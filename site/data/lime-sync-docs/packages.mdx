# Packages and source map

Lime Sync ships from this repository as the `limesync` npm package. It was previously
published as `orez-lite`; that name is deprecated.

## Public JavaScript exports

| Package/export             | Purpose                                                        | Status  |
| -------------------------- | -------------------------------------------------------------- | ------- |
| `limesync/client`          | Browser transport plugin for the real Zero client              | Preview |
| `limesync/browser`         | Durable browser worker host with Bedrock SQLite and IndexedDB  | Preview |
| `limesync/native`          | Native SQLite host entrypoint                                  | Preview |
| `limesync/cloudflare`      | Cloudflare deployment tools                                    | Preview |
| `limesync/cloudflare/sync` | Rust/WASM sync host for Cloudflare Workers and Durable Objects | Preview |

## Engine and host packages

| Source package      | Role                                                                 |
| ------------------- | -------------------------------------------------------------------- |
| `sync-core`         | Deterministic pull, push, value, retention, query, and schema engine |
| `sync-native`       | Axum and rusqlite native host                                        |
| `sync-wasm`         | WASM boundary for constrained JavaScript hosts                       |
| `orez-sync-cf-host` | Cloudflare Worker and Durable Object integration                     |

Applications should use the documented parent-package exports. The internal
`sync-*` packages remain repository build units and may change as the public
Lime Sync package is established.
