# Packages and source map

The table below lists Orez’s public packages and supporting implementation packages.

## JavaScript packages

| Package/export         | Purpose                                                          | Status                         |
| ---------------------- | ---------------------------------------------------------------- | ------------------------------ |
| `orez`                 | All-in-one runner, CLI, configuration, and `startZeroLite()`     | Primary                        |
| `orez/vite`            | Bind Orez to a Vite dev-server lifecycle                         | Primary                        |
| `orez/s3`              | Small local S3-compatible server for development                 | Primary, intentionally limited |
| `orez/change-tracking` | PGlite change-tracking implementation details                    | Internal/advanced              |
| `drizzle-zero-sqlite`  | Generate a Zero schema from Drizzle SQLite definitions           | Public utility                 |
| `bedrock-sqlite`       | WASM SQLite adapter used by Orez and related repository packages | Workspace package              |

## Versioning guidance

- Pin Orez and Zero together in applications that depend on internal compatibility layers.
- Prefer documented top-level APIs over worker, proxy, or change-tracking internals.
- Record the database profile, Zero version, and SQLite implementation in reproducible test reports.
