# Orez documentation

Orez is an easy, all-in-one way to run Zero locally. It manages zero-cache,
its databases, replica storage, migrations, and process lifecycle from one
configuration.

```sh
bunx orez
```

## What Orez manages

Orez coordinates the services around a stock Zero application:

- zero-cache and its replica storage;
- PGlite or Embedded Postgres;
- migrations and application lifecycle hooks;
- local object storage and admin controls; and
- stable addresses for development and CI.

Your application keeps the real `@rocicorp/zero` client, schema, named queries,
custom mutators, and optimistic local state.

## Recommended path

1. Run the [quick start](/docs/getting-started).
2. Keep [PGlite/WASM](/docs/node/pglite) for the smallest local and CI setup.
3. Switch to [Embedded Postgres](/docs/node/embedded-postgres) when you need
   production-like concurrency and logical replication.
4. Move repeatable settings into [Configuration and CLI](/docs/node/configuration).

Lite Sync, the SQLite-native replacement sync server, now has its own
[documentation site](https://lite-sync-docs.natewienert.workers.dev).
